## Day 7: Training and Testing Data

**Project:** Student Score Prediction using Train/Test Split

### What I built

- Split the dataset into training and testing sets using `train_test_split`.
- Trained a Linear Regression model using training data.
- Predicted scores using testing data the model had not seen during training.
- Evaluated the predictions using Mean Absolute Error (MAE).

### What I learned

- The difference between training data and testing data.
- Why testing a model on unseen data is important.
- How to evaluate a model's predictions.
