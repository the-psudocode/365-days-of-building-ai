# Day 13 – Student Performance Dataset

## Objective

Create a manually generated student dataset using Python and Pandas for the Student Performance AI project.

## Work Completed

- Created a Pandas DataFrame containing 20 synthetic student records.
- Added five input features:
  - Study hours
  - Attendance
  - Previous exam score
  - Sleep hours
  - Assignment completion
- Added `final_score` as the prediction target.
- Exported the DataFrame to `data/student_data.csv`.
- Inspected the dataset using `head()`, `shape`, `info()`, and `describe()`.
- Checked for missing values and duplicate records.

## Dataset Results

- Total records: 20
- Total columns: 6
- Missing values: 0
- Duplicate records: 0
- Average final score: 64.7

## Technologies

- Python
- Pandas

## Important Learning

- Creating DataFrames from Python dictionaries.
- Understanding features and target variables.
- Exporting datasets to CSV.
- Basic data quality checks and statistical analysis.

## Limitation

The dataset contains synthetic records created for learning. It is not representative of real student populations and is too small for reliable real-world predictions.
