# Day 14 – Exploratory Data Analysis (EDA) and Data Visualization

## Objective

Perform Exploratory Data Analysis (EDA) on the Student Performance dataset to understand the relationships between different student features and final scores.

## Project

Student Performance AI – Student Performance Predictor

## Tools and Libraries

- Python
- Pandas
- Matplotlib

## Tasks Completed

### 1. Dataset Loading and Inspection

- Loaded the student dataset using Pandas.
- Inspected dataset information using `df.info()`.
- Checked the number of records, columns, and data types.
- Verified that there were no missing values.

### 2. Study Hours vs Final Score

Created a scatter plot to understand the relationship between daily study hours and students' final scores.

### 3. Attendance vs Final Score

Created a scatter plot to explore the relationship between attendance percentage and final scores.

### 4. Final Score Distribution

Created a histogram to understand how students' final scores are distributed.

### 5. Correlation Analysis

- Calculated the correlation matrix using `df.corr()`.
- Visualized correlations using Matplotlib's `imshow()`.
- Used a color scale to interpret positive and negative relationships.

## Concepts Learned

- Exploratory Data Analysis (EDA)
- Data inspection using Pandas
- Scatter plots
- Histograms
- Correlation
- Correlation matrices
- Heatmaps
- Matplotlib visualization

## Key Learning

EDA helps us understand our dataset before training a machine learning model. Visualizations and correlation analysis help identify patterns and relationships between features.

Correlation indicates association, not causation.
