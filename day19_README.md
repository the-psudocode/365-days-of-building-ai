# Day 19 – Student Performance AI: Student Analysis Dashboard

## Overview

On Day 19 of the 365 Days of Building AI challenge, I developed an interactive Student Analysis Dashboard for the Student Performance AI application.

The dashboard uses Pandas and Matplotlib to analyze student academic data and present meaningful visual insights.

## Objectives

- Build an interactive analytics dashboard.
- Calculate important student performance statistics.
- Visualize relationships between academic features.
- Analyze student score distribution.
- Generate automatic data insights.

## Features Implemented

### 1. Dashboard Metrics

Displayed four important statistics:

- Total number of students
- Average final score
- Average daily study hours
- Average attendance percentage

### 2. Data Visualizations

Implemented three visualizations:

**Study Hours vs Final Score**

- Scatter plot showing the relationship between daily study hours and final scores.

**Attendance vs Final Score**

- Scatter plot exploring the relationship between attendance and final scores.

**Final Score Distribution**

- Histogram showing how student scores are distributed across different ranges.

### 3. Automatic Data Insights

The dashboard calculates:

- Highest student score
- Lowest student score
- Number of students scoring 80 or above
- Average final score

### 4. Feature Correlations

Calculated Pearson correlation coefficients:

- Study hours vs final score: 0.98
- Attendance vs final score: 0.99

These values indicate very strong positive linear associations in the current synthetic dataset.

## Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib
- Scikit-learn

## Concepts Learned

- Data analysis using Pandas
- Statistical calculations using mean, max and min
- Scatter plots and histograms
- Data visualization using Matplotlib
- Correlation analysis
- Boolean filtering in Pandas
- Integrating analytics into a Streamlit application

## Important Note

The application currently uses a small synthetic dataset containing 20 student records.

The correlation values and insights are for educational purposes and should not be interpreted as established real-world relationships or causal effects.

## Outcome

Successfully transformed the Student Performance AI application into an interactive analytics platform with statistical metrics, visualizations and automatic data insights.
